# Creature Context

Creature Context is a separate, local-first context system for coding platforms.

It maintains a multiscale Atlas of codebases, their module relationships and evidence-backed Green status. Orbit supplies a reproducible, token-bounded view of that Atlas from Galaxy architecture to Moon implementation detail.

## Protected decisions

- Creature Context must remain useful without CreatureIDE.
- Deterministic and human evidence outrank model inference.
- `PURPOSE.md` is human-authored and must never be silently rewritten.
- Paths are attributes; stable identifiers are canonical.
- Models are optional and cannot independently produce Green status.
